## Замер токенов
За реализацию фичи "список заметок" (Task 2) было сделано 7 AI-запросов, суммарно ~1 228 400 токенов (данные из Cursor Dashboard → Usage, модель auto).

## Оценка стоимости
При ставке ~$6/1M токенов (смешанная модель auto) оценочная стоимость фичи — ~$7.37. Примечание: реальный биллинг идёт по фиксированному Pro-плану ($20/mo), точного счёта за фичу нет — это оценка по рыночной цене токенов.

## Анализ контекста (repomix)
Общий контекст проекта: 71 255 токенов, 103 файла.
Самый "тяжёлый" файл — app/.agents/skills/vercel-react-best-practices/AGENTS.md: 26 362 токена (37% всего контекста).

## Выводы и оптимизации
1. Скилл vercel-react-best-practices съедает больше трети контекста — стоит подгружать его выборочно, а не держать постоянно в контексте агента.
2. Для рутинных, некритичных задач (обновление metadata, мелкие правки) можно использовать более дешёвую/быструю модель вместо "auto", чтобы не тратить лимит на простые операции.
3. Короткие, чёткие промпты с конкретными acceptance criteria (как в Task 2) снижают число итераций и, соответственно, расход токенов по сравнению с расплывчатыми запросами.
