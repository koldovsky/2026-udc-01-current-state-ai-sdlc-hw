# Workflow — фіча «Список заметок»

Документ описує процес реалізації фічі для Task 2 домашнього завдання WS1: plan → agent + перевірка.

---

## Acceptance criteria

1. **Поле ввода текста и кнопка «Добавить»** — форма з `<input>` і кнопкою submit.
2. **При нажатии заметка появляется в списке** — після додавання текст з'являється в `<ul>` під формою.
3. **У каждой заметки кнопка «Удалить»** — окрема кнопка на кожному елементі списку.
4. **Пустую заметку добавить нельзя** — перевірка `trim()`; кнопка «Добавить» disabled для порожнього або пробільного вводу.
5. **Список отображается под формой** — у JSX спочатку форма, потім список.

### Ключові рішення в коді

- Тип заметки: `{ id: string; text: string }`, `id` через `crypto.randomUUID()`.
- Додавання: `handleAdd` з `preventDefault`, `trim()`, очищення поля після успіху.
- Видалення: `handleDelete` фільтрує масив за `id`.
- Додатково: submit по Enter, `aria-label` на кнопках видалення, placeholder «Заметок пока нет» для порожнього списку.
