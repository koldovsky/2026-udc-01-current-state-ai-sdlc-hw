## Project Rules & Context

## Stack
- Vite + React
- Language: JavaScript (JSX)
- Package Manager: npm

## Commands
- Dev: npm run dev
- Build: npm run build
- Preview: npm run preview

## Conventions
- Use Functional Components.
- Use Arrow Functions.
- Keep components small and focused.
- Name files in PascalCase (e.g., MyComponent.jsx).
- Use CSS Modules for styling.

## Guardrails
- DO NOT use Class Components.
- DO NOT install new heavy libraries without asking.
- DO NOT change vite.config.js unless requested.

## Language
- Always communicate with the user in Ukrainian.
