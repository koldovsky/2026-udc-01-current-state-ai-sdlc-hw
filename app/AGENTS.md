## Conventions

1. **Naming** — React components in `PascalCase`; files/directories in `kebab-case`. Use the `@/*` path alias (maps to project root) for all non-relative imports.
2. **Routing** — All routes live under `app/`. Shared UI goes in `app/components/`, shared types in `types/`. Never mix App Router and Pages Router.
3. **Server vs client components** — Default to Server Components. Add `"use client"` only when you need browser APIs, event handlers, or React hooks. Keep client boundaries as leaf nodes.
4. **Styling** — Tailwind utility classes only. No CSS Modules, no inline `style` props, no external CSS libraries. Dark mode via the `dark:` variant.
5. **TypeScript** — `strict: true` is non-negotiable. No `any`, no `// @ts-ignore`. Prefer `type` over `interface` unless declaration merging is required.

## Guardrails

1. **Do not touch `next-env.d.ts`** — auto-generated by Next.js; manual edits are overwritten silently.
2. **Do not create a `pages/` directory** — the project is App Router only. Adding a Pages Router entry will cause routing conflicts.
3. **Do not weaken TypeScript config** — never set `strict: false`, `noImplicitAny: false`, or add `skipLibCheck` overrides beyond what's already in `tsconfig.json`.
