Workflow: Feature Tech Stack List
## Acceptance Criteria (AC):
1. Під лічильником є поле вводу (input) для назви нової навички.
2. Є кнопка "Додати", яка додає навичку до списку.
3. Список відображається нижче, кожен елемент має кнопку "Видалити".
4. Якщо поле вводу порожнє, кнопка "Додати" не повинна спрацьовувати.
5. Стилі мають відповідати загальному дизайну сторінки.
